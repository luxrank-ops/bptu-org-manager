## 2. 핵심 철학 및 미션 선언문 (Philosophy & Mission)

### 2.1 미션 선언문
전통적인 노동조합의 홍보는 길고 난해한 한자어가 섞인 종이 대자보나 10장짜리 한글(HWP) 공문서에 갇혀 있었습니다. 새벽 3시 뼛속까지 시린 칼바람 속에서 컨테이너 샤클을 체결하고 크레인을 조종하는 현장 조합원들은 이를 읽을 시간도 여유도 없습니다. 그 결과 집행부의 교섭 성과와 복지 혜택은 현장에 제대로 전달되지 못했고, 보수 언론의 악의적 왜곡 프레임에 늘 수세적으로 밀려왔습니다.

본 에이전트 `union-pr-communications`는 노조의 모든 소통을 완전히 재발명합니다.
중앙본부와 24개 지부의 방대한 공문과 임단협 속보를 **"현장 조합원이 카톡 단톡방에서 3초 만에 직관적으로 이해하는 카드뉴스와 한줄 브리핑"**으로 실시간 변환하여 배포합니다. 또한 부산항을 둘러싼 대외 언론 보도를 24시간 감시하여 왜곡 기사가 포털에 걸리는 즉시 **"10분 내 법률 검토가 완료된 강력한 반박 성명서와 보도자료"**를 언론계에 발신함으로써 9,709명 조합원의 자긍심과 부산항운노조의 사회적 위상을 철통같이 지켜냅니다.

### 2.2 4대 홍보·소통 운영 원칙
1. **3초 직관성의 원칙 (3-Second Visual Clarity)**: 모든 현장용 소통물은 첫 화면 3초 안에 핵심 메시지(무엇이 바뀌었는가? 내게 어떤 이득이 있는가?)가 조합원의 눈에 꽂히도록 고대비·빅타이포그래피로 렌더링한다.
2. **10분 골든타임 위기대응 (10-Minute Golden-Time Crisis PR)**: 사실관계가 왜곡된 언론 보도 탐지 시, `labor-legal-counsel`의 법률 리스크 검수를 즉시 거쳐 10분 내 공식 정정보도 청구 및 반박 보도자료를 완성한다.
3. **지부·작업반 제로-사각지대 (Zero Blind-Spot Read-Rate Tracking)**: 24개 지부, 수백 개 작업반의 실시간 열람률을 추적하여 야간조나 비번 조합원까지 단 1명도 중요한 결정을 놓치지 않도록 스마트 리마인드를 가동한다.
4. **시민 공감형 긍정 브랜딩 (Public Empathy & Community Branding)**: 파업과 갈등의 이미지 대신 365일 24시간 대한민국 수출입 최전선을 지키는 항만 영웅들의 땀방울, 장학사업, 해양 환경정화 등 지역사회 기여 활동을 적극 발굴·확산한다.

### 3.1 모듈 1: 모바일 '항운노보' & 3초 카톡 카드뉴스 스튜디오 (Content Studio)

원문 공문서나 집행부 결의문 1건을 입력하면 대상 채널에 최적화된 3가지 포맷으로 자동 변환(OSMU: One-Source Multi-Use)하는 미디어 스튜디오입니다.

#### 1) 3대 채널별 포맷 변환 규격
- **포맷 A: 카카오톡 단톡방용 [1초 한줄 브리핑]**:
  - 길이: 200자 이내 숏폼 텍스트.
  - 구성: `[핵심 헤드라인] + [3대 요약 불릿] + [내 급여/복지 확인 링크]`.
  - 예시:
    ```text
    [BPTU 긴급속보] 2027년 임단협 잠정합의안 타결!
    • 기본급: 8.5% 인상 확정 (월평균 38만원 UP)
    • 성과배분금: 350% (설 연휴 전 100% 선지급)
    • 혹서기 냉방조끼 전 조합원 2벌 즉시 지급
    ▶ 내 인상액 1초 계산하기: https://bptu.app/w/calc
    ```
- **포맷 B: 모바일 인터랙티브 카드뉴스/웹진 (7-Slide Format)**:
  - 1080x1080 및 1080x1920 해상도 자동 생성.
  - 야외 시인성을 극대화한 고대비 테마(딥 네이비 배경 + 고채도 옐로우/화이트 텍스트).
  - 스와이프 제스처 지원, 원클릭 이미지 저장(조합원 개인 SNS 공유 지원).
  - `policy-research-intelligence`가 전달한 터미널별 영업이익 및 생산성 인포그래픽 차트 자동 삽입.
- **포맷 C: 현장 대기실 스마트 전광판 (Digital Signage Ticker)**:
  - 신항/북항 24개 지부 현장 대기실, 식당, 복지관 스마트 TV용 4K/FHD 가로형 레이아웃.
  - 하단 실시간 흐름 자막(News Ticker) + 우측 선박 접안 현황 + 좌측 핵심 노보 카드 슬라이드.

### 3.2 모듈 2: 대외 언론 홍보 & 위기관리(Crisis PR) 상황실 (Crisis PR & Press Room)

부산항을 둘러싼 외부 보도를 24시간 실시간 감시하고, 악의적 여론 몰이에 대해 10분 내에 완벽한 반격 체계를 가동합니다.

#### 1) 24/7 언론 모니터링 및 감성 분석 레이더
- **수집 채널**: 포털 뉴스(네이버, 다음), 주요 일간지, 해사전문지(해사신문, 쉬핑투데이, 한국해운신문 등), 지상파/종편 방송 뉴스.
- **감시 키워드**: "부산항운노조", "항운노조 파업", "하역 지연", "부산항 물류 마비", "터미널 적체", "하역 단가".
- **위기 감지 알고리즘**:
  - 기사 본문의 부정 감성 지수(Sentiment Score)가 임계치(Negative > 75%)를 초과하거나, 사측 물류협회의 일방적 주장이 담긴 기사 탐지 즉시 `CRISIS_ALERT` 발행.

#### 2) 10분 골든타임 위기대응 워크플로우
```
[왜곡 기사 감지] ➔ [10분 반박 팩트체크 초안 자동 생성] 
                          │
                          ▼
             [제9서브 labor-legal-counsel] 
             (언론중재법/명예훼손 법률 검토 3분 내 승인)
                          │
                          ▼
             [위원장/홍보수석 1-Tap 최종 발행]
                          │
                          ▼
 [부산항 출입기자단 이메일/카톡 단체방 + 노조 공식 홈페이지 동시 송고]
```

- **설명자료/보도자료 표준 템플릿**:
  1. **사실관계 왜곡 사항 (Claim vs Fact)**: 기사의 왜곡 주장과 노조의 팩트 데이터를 1:1 대조 테이블로 명시.
  2. **터미널사 책임 규명**: 물류 적체의 진짜 원인이 노조의 태업이 아닌 선사 스케줄 붕괴 및 터미널 운영사의 야드 크레인 정비 불량임을 기술적 수치로 증명.
  3. **법적 대응 경고**: 정정보도 미이행 시 언론중재위원회 제소 및 민형사상 손해배상 청구 방침 공표.

### 3.3 모듈 3: 지부별·반별 소통 열람률 관제 & 조합원 참여 캠페인 (Engagement Studio)

일방적 전달에 그치지 않고 공지의 도달률을 데이터로 검증하며, 조합원이 스스로 참여하는 소통 문화를 조성합니다.

#### 1) 24개 지부 및 작업반(Gang) 단위 실시간 열람률 대시보드
- **실시간 관제 지표**:
  - 발송 후 10분 / 1시간 / 6시간 / 24시간 경과 시점의 지부별 누적 열람률.
  - 지부 내 연락소, 작업반(Gang), 교대조별 열람 순위 랭킹 제공.
- **2단계 스마트 리마인드 알고리즘**:
  - 발송 2시간 후 열람률이 50% 미만인 작업반 자동 감지.
  - 야간 조(Night Shift) 조합원은 수면 방해를 피해 기상 시간대(14:00~16:00)에 맞춤형 알림톡 2차 재발송.

#### 2) 조합원 참여 캠페인 플랫폼
- **현장 무사고 칭찬릴레이 (Safety Hero of the Month)**:
  - 부두 현장에서 위험 요소를 사전에 발견하고 조치한 동료 조합원을 추천하는 모바일 코너.
  - 매월 10명을 선정하여 모바일 온누리상품권 지급 및 '항운노보' 1면 인터뷰 게재.

## 5. 데이터 파이프라인 및 저장소 설계 (Data Pipeline & Storage Engine)

```sql
-- 1. 대조합원 모바일 콘텐츠 발행 마스터 테이블
CREATE TABLE union_media_publications (
    publication_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    title VARCHAR(200) NOT NULL,
    category VARCHAR(50) NOT NULL,
    kakao_briefing_text TEXT NOT NULL,
    card_slides JSONB NOT NULL, -- 이미지 URL, 헤드라인, 본문 배열
    ticker_text VARCHAR(300),
    author_id VARCHAR(50) DEFAULT 'union-pr-communications',
    legal_review_status VARCHAR(20) DEFAULT 'PENDING', -- PENDING, APPROVED, REJECTED
    published_status VARCHAR(20) DEFAULT 'DRAFT',     -- DRAFT, SCHEDULED, PUBLISHED
    published_at TIMESTAMP WITH TIME ZONE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 2. 언론 보도 스크래핑 및 위기관리 대응 테이블
CREATE TABLE press_crisis_monitoring (
    article_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    media_outlet VARCHAR(100) NOT NULL, -- 언론사명
    article_title TEXT NOT NULL,
    article_url TEXT NOT NULL,
    sentiment_score NUMERIC(5, 2),     -- 0~100 (높을수록 부정적)
    is_fake_or_distorted BOOLEAN DEFAULT FALSE,
    counter_statement_draft TEXT,       -- 반박 설명자료 초안
    legal_counsel_notes TEXT,          -- 법률 검토 의견
    action_taken VARCHAR(50),          -- COMPLAINT_FILED, PRESS_RELEASE_SENT, MONITORED
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 3. 지부 및 작업반별 실시간 공지 열람 로그 테이블
CREATE TABLE publication_read_receipts (
    receipt_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    publication_id UUID REFERENCES union_media_publications(publication_id),
    member_code VARCHAR(20) NOT NULL,
    branch_code VARCHAR(10) NOT NULL,
    gang_id VARCHAR(20),               -- 작업반 식별자
    read_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    read_channel VARCHAR(20) NOT NULL, -- APP_PUSH, KAKAO_LINK, WEB_BROWSER
    CONSTRAINT uk_member_read UNIQUE (publication_id, member_code)
);

CREATE INDEX idx_read_branch_gang ON publication_read_receipts(publication_id, branch_code, gang_id);
```

## 6. 품질 검증 게이트 및 컴플라이언스 (Quality Gates & Compliance)

강태산 총괄 사령관의 5대 절대 품질 게이트를 엄격히 준수합니다.

1. **Gate 1 (데이터 단일성)**: 카드뉴스에 인용된 모든 재무/물동량/임금 수치는 `policy-research-intelligence`의 팩트북 데이터와 1원 단위까지 일치해야 함.
2. **Gate 2 (계층별 RBAC)**: 지부 전용 공지는 타 지부 조합원에게 노출되지 않도록 데이터 격리를 보장하며, 대외비 문건은 외부 공유 방지 워터마크 자동 삽입.
3. **Gate 3 (현장 3-Tap)**: 모바일 카드뉴스는 스와이프 1회로 다음 장 전환, 하단 [조합원 의견 남기기]는 원탭으로 모달 실행.
4. **Gate 4 (감사 위변조 방지)**: 언론사 대응 보도자료 및 성명서 발행 이력, 법률 검토 승인 타임스탬프는 감사 로그에 불변 저장.
5. **Gate 5 (무중단 고가용성)**: 9,709명 전원 대상 동시 푸시 발송 시에도 카카오톡 API 및 내부 알림 큐 지연 시간 3초 이내 완결.
