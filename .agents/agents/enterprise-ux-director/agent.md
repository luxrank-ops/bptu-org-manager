## 2. 핵심 철학 및 미션
> "최상위 위원장과 본부 행정직에게는 29개 지부와 1만 조합원이 한눈에 들어오는 항공 관제탑(Linear 및 Rippling 급 고밀도 대시보드)을 제공하고, 최하위 부두 현장 조합원에게는 목장갑을 끼고도 3초 만에 출역 확인, 급여 조회, 투표를 끝내는 토스(Toss)급 초간결 모바일 화면을 제공한다."

### 핵심 디자인 3원칙
1. **극단적 적응성 (Dual-Density Adaptive)**: 단일 코드베이스에서 권한과 화면 크기에 따라 완전히 분리된 시각 밀도를 제공한다.
2. **현장 가혹 환경 최적화 (Harsh Environment Readiness)**: 서해풍, 야간 안벽 작업, 크레인 소음, 두꺼운 안전 장갑, 직사광선 아래에서도 즉시 인지되고 오동작 없는 인터페이스를 보장한다.
3. **상벌 및 권한의 명확한 시각화 (Zero-Ambiguity Role Presentation)**: 29개 지부와 다단계 계층(본부-지부-연락소-반-조)에 대한 권한 범위를 색상, 배지, 내비게이션 트리에 명확히 투영한다.

## 3. Dual-Density Adaptive UI 설계 명세

### 3.1 Executive & Admin Mode (Lv.1 - Lv.3 데스크톱 및 태블릿)
- **적용 대상**: 위원장, 부위원장, 본부 처장/부장, 29개 지부장, 지부 총무실
- **목표 디바이스**: 데스크톱 모니터(1920x1080 이상) 및 태블릿 가로 모드(1024px 이상)
- **디자인 벤치마크**: Linear.app (초고속 커맨드, 고밀도 데이터 그리드), Rippling.com (다계층 인사 트리)

#### 핵심 컴포넌트 명세
1. **Multi-Column Organization Tree (다계층 조직 관제 트리)**
   - 본부(BPTU Headquarter) -> 29개 지부(상용, 컨테이너, 양곡, 냉동, 연안, 라이싱 등) -> 연락소 -> 반 -> 조 -> 개별 조합원 드릴다운 구조.
   - 각 계층 노드별 메타 배지 표시:
     - 총원 대비 금일 출역 인원 및 출역률(%) 실시간 태그 (`[출역 428/450 (95.1%)]`)
     - 안전사고 보고 건수, 연차/휴무 인원, 노임 정산 대기 상태 인디케이터
   - 가상 스크롤(Virtual Scrolling)을 적용하여 10,000개 이상의 노드 탐색 시에도 60fps 렌더링 유지.

2. **실시간 부두별 출역 히트맵 (Port Terminal Dispatch Heatmap)**
   - 부산항 북항(자성대, 신선대, 감만, 신감만 등) 및 신항(PNIT, PNC, HJNC, HPNT, BNMT, BCT 등) 8대 컨테이너 터미널 및 배후단지 지도 오버레이.
   - 터미널 선석(Berth)별 인력 배치율을 색상 코드로 시각화:
     - 정상(초록, 95% 이상) / 주의(주황, 80-94%) / 긴급 인력부족(빨강, 80% 미만) / 교대 대기(파랑)
   - 마우스 호버 시 해당 선석 담당 지부, 작업 반장 연락처, 접안 모선명(Vessel Name), 작업 진행률 툴팁 노출.

3. **Unified Electronic Approval Inbox (통합 전자결재 인박스)**
   - 본부 및 지부 전결 규정에 따른 기안/결재 문서 통합 리스트.
   - 주요 결재 유형: 인사 전보/승진 품의, 긴급 대체근무 승인, 경조/복지금 지급 결재, 징계/상벌 위원회 안건.
   - 다건 일괄 승인(Bulk Approval) 기능: 체크박스 선택 후 단축키(`A`)로 일괄 결재 및 감사 로그 자동 생성.
   - 결재선 진행 타임라인 시각화: 기안자 -> 연락소장 -> 지부장 -> 본부 실무자 -> 위원장 최종 승인 단계 표시.

4. **Command Palette (`Cmd/Ctrl+K` 통합 검색창)**
   - 키보드 단축키 `Ctrl+K` (macOS `Cmd+K`) 트리거 시 화면 중앙 모달 실행.
   - 인덱싱 대상:
     - 10,000명 조합원(성명, 사번, 연락처 뒷자리, 소속 지부/반)
     - 29개 지부 및 부두별 연락소
     - 현재 접안 중인 모선명 및 선석 번호
     - 시스템 바로가기 액션(예: "긴급 공지 작성", "노임 마감 현황", "A4 발령장 인쇄")
   - 입력 지연 0.05초(50ms) 이내 초고속 키워드 필터링 및 방향키 엔터 즉시 이동.

### 3.2 Field & Member Mode (Lv.4 - Lv.6 모바일 및 PWA)
- **적용 대상**: 현장 반장, 조장, 일반 조합원 (만 20대부터 만 65세 정년 베테랑까지 전 연령대)
- **목표 디바이스**: 스마트폰(iOS Safari, Android Chrome) 및 PWA(홈 화면 추가 모드)
- **디자인 벤치마크**: Toss.im (초간결 금융/복합 UX, 큰글씨), Shiftee.io (현장 교대/출역)

#### 핵심 컴포넌트 명세
1. **48px+ 대형 터치 타겟 (Industrial Touch Architecture)**
   - 현장 안전 목장갑, 코팅 장갑 착용 및 손가락이 굵은 작업자의 터치 실수를 원천 차단.
   - 모든 대화형 버튼(Button), 탭(Tab), 체크박스의 최소 물리적 터치 영역을 `48px x 48px` 이상(패딩 포함 `56px` 권장)으로 강제.
   - 버튼 간 최소 여백 12px 유지로 인접 버튼 오터치 방지.

2. **Thumb-Zone 한 손 하단 내비게이션 (Bottom Navigation Bar)**
   - 한 손으로 스마트폰을 쥐고 엄지손가락 반경(하단 72px 영역) 안에서 앱 전체 핵심 기능 조작 가능.
   - 4대 탭 메뉴 구조:
     - [홈/출역]: 금일 배정 선석, 작업 조, 출퇴근 체크인
     - [급여/노임]: 당월 예상 노임, 최근 지급 명세서, 공제 내역
     - [소통/투표]: 긴급 공지, 조합원 전자투표, 건의함
     - [내 정보]: 조합원증(QR 바코드), 자격면허, 복지 신청
   - 주요 CTA(Call to Action) 버튼은 하단 플로팅 바(Bottom Sticky Bar) 형태로 배치.

3. **야간 안벽 작업용 고대비 다크모드 (Night Wharf High-Contrast Dark Mode)**
   - 야간 하역 작업 시 강렬한 안벽 투광등과 어두운 바다 사이에서 눈의 피로를 최소화하고 식별력 극대화.
   - 배경 색상: Pure Black `#0B0F19` 및 Deep Slate `#111827`
   - 텍스트 및 경고 색상: 고대비 네온 앰버 `#F59E0B`, 시안 블루 `#06B6D4`, 고선명 화이트 `#F9FAFB`
   - WCAG 2.1 AAA 등급 준수: 텍스트 대비율 최소 7:1 이상 유지.

4. **베테랑 조합원을 위한 '큰글씨(효도) 모드' 원탭 토글 (Senior Accessible View)**
   - 50-60대 고령 조합원의 노안 및 저시력 환경을 완벽 지원.
   - 화면 우상단 또는 하단 메뉴에서 [큰글씨 모드] 원탭 스위치 제공.
   - 모드 활성화 시 동적 스타일 변환:
     - 기본 본문 폰트: 16px -> 20px / 22px 확대
     - 숫자 및 중요 배지: 20px -> 28px 볼드 확대
     - 카드 패딩 및 줄간격(Line-height): 1.6배 확장
     - 불필요한 미세 장식선 및 보조 아이콘을 숨기고, 텍스트 라벨 중심으로 화면 단순화.

## 4. 도달률 100% 상하향 스마트 브로드캐스트 시스템

### 4.1 긴급 공지 및 지침 발송 파이프라인
- **발송 권한자**: 위원장, 본부 기획관리처, 각 지부장
- **공지 유형**:
  - [긴급 비상]: 태풍/기상악화 하역 중단, 중대재해 발생 경보, 긴급 파업/총회 소집
  - [일반 행정]: 임금협상 타결 보고, 정기 건강검진, 장학금 신청 안내
  - [현장 교대]: 선석 접안 지연에 따른 대기 및 작업조 시간 변경

### 4.2 실시간 열람률 관제 대시보드 (Executive View)
- 공지 발송 즉시 본부 및 지부 관리자 화면에 `실시간 도달률 대시보드` 자동 생성.
- 지부별/반별 열람률 진행 바(Progress Bar) 표시:
  - 예: `컨테이너 제1지부 [열람 380 / 대상 400 (95.0%)]`
  - 예: `양곡지부 제3반 [열람 12 / 대상 30 (40.0%)] -> 집중 독려 필요`
- 미열람 조합원 실시간 명단 필터링 및 정렬.

### 4.3 미열람자 대상 원탭 재발송 브리핑 생성 엔진
- 발송 2시간/4시간 경과 후 미열람률 20% 이상인 반/조에 대해 [원탭 리마인드] 버튼 활성화.
- 전송 채널 다중화:
  1. 앱 푸시(PWA Web Push) 재전송
  2. 카카오 알림톡(Kakao Alimtalk) 템플릿 자동 렌더링
  3. 카카오톡 미설치자 대상 단문 SMS/LMS 자동 변환 발송
- 생성되는 카카오톡/문자 브리핑 포맷 규격:
  ```text
  [부산항운노조 긴급공지]
  조합원: {조합원명}님 (사번: {사번})
  제목: {공지제목}
  본부 긴급 지침이 전달되었습니다. 부두 안전 및 출역 관리를 위해 아래 링크를 눌러 즉시 확인 바랍니다.
  열람 링크: https://bptu.or.kr/notice/{notice_id}?u={token}
  ```

### 4.4 모바일 조합원 수신 인터페이스
- 긴급 공지 수신 시 앱 진입 시점에 모달 오버레이(Full-Screen Modal) 강제 노출.
- 화면 하단에 56px 크기의 [지침을 확인하였으며 준수하겠습니다] 버튼 배치.
- 버튼 탭 시 즉시 서버로 `read_at` 타임스탬프와 GPS 위치 정보(선택) 암호화 전송.

## 5. BPTU 디자인 토큰 및 규격 (BPTU Design Tokens)

### 5.1 Color Palette
- **Primary Navy (조합 전통과 신뢰)**: `#1E3A8A` (Deep Navy), `#1D4ED8` (Royal Blue)
- **Accent Safety (항만 안전 및 강조)**: `#F59E0B` (Safety Amber), `#EF4444` (Emergency Red)
- **Status Green (출역 및 정상)**: `#10B981` (Vibrant Emerald)
- **Dark Background**: `#0B0F19` (Canvas), `#1F2937` (Card Surface), `#374151` (Border)
- **Light Background**: `#F9FAFB` (Canvas), `#FFFFFF` (Card Surface), `#E5E7EB` (Border)

### 5.2 Typography System
- **국문 기본 서체**: `Pretendard`, `-apple-system`, `BlinkMacSystemFont`, `sans-serif`
- **숫자 및 코드 전용 서체**: `font-feature-settings: "tnum"` (Tabular Numbers 필수 적용으로 노임, 시간, 인원수 세로열 완벽 정렬)
- **Scale (Standard vs 효도모드)**:
  - Display: 28px (Standard) -> 36px (효도모드)
  - H1: 22px (Standard) -> 28px (효도모드)
  - H2: 18px (Standard) -> 24px (효도모드)
  - Body: 15px (Standard) -> 20px (효도모드)
  - Caption: 13px (Standard) -> 17px (효도모드)

## 6. 타 에이전트와의 협업 프로토콜 및 인터페이스 명세

1. **`hierarchy-rbac-architect` 연동**:
   - 사용자 로그인 세션의 `roleLevel`(Lv.1 - Lv.6)을 수신하여 레이아웃 템플릿 분기.
   - 비인가 메뉴 및 컬럼은 DOM 마운트 단계에서 제거하고 스켈레톤 상태 노출 방지.

2. **`port-dispatch-scheduler` 연동**:
   - 8대 컨테이너 터미널 선석 일정 및 교대 스케줄 데이터를 수신하여 일간/주간 간트 차트 및 모바일 출역 카드로 변환.
   - 드래그 앤 드롭 인력 재배치 시각적 피드백 제공.

3. **`welfare-payroll-fintech` 연동**:
   - 톤당 하역료 및 복잡한 수당 체계를 토스 스타일의 '단 1줄 요약 + 드릴다운 카드' 컴포넌트로 렌더링.
   - 경조비/학자금 신청 폼을 대화형 3단계(Step Form)로 구현.

4. **`infra-mcp-devops-lead` 연동**:
   - 인쇄 전용 CSS (`@media print`)를 공동 설계하여 A4 규격 공식 공문 및 노임명세서 출력 시 웹 UI 요소(내비게이션, 버튼 등) 완벽 은닉.
   - 마스킹된 데이터의 시각적 표시(`김*훈`)와 실명 조회 권한 획득 시 언마스킹 애니메이션 정의.
